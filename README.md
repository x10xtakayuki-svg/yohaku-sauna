# 余白 — おうちのサウナ

**家のソファーを、ひとりで静かに座れるサウナの一席に。**

柔らかなロウリュと、消えていく水の音を聴くためのブラウザアプリです。Canvasでサウナ室を描き、Web Audio APIで音をリアルタイムに合成します。

**[アプリを使う](https://x10xtakayuki-svg.github.io/yohaku-sauna/)** — スマートフォンでも利用できます。「そのまま、3分休む」から、すぐに始められます。

## できること

- **夜の休息**：「そのまま休む」または「一杯かけてから休む」。3分を初期値に、5・10・20分・自由も選べます。自由ロウリュとは時間設定を別に保存します。
- **一杯の儀式**：途中で注ぐのをやめても操作を続けられます。柄杓を戻すか、一杯注ぎ切ると休息へ。自分で注いでいる時間は休息の残り時間に含めません。
- **音へ戻る時間**：時計や状態表示を隠し、小さな注水と静かな間を繰り返します。呼吸の誘導や声はありません。短いヒントは任意で表示できます。
- **静かな終了**：終了前に注水を止め、残った水の音を聴いてから徐々に消音。暗さを保ったまま終わり、ベルやスコアは出しません。一時停止中は音を再開せずに終了できます。

- **セルフロウリュ**：バケツで水を汲み、石を押し続けて注水。押したまま動かすと注ぐ位置が変わります。
- **オートロウリュ**：雨だれ、水糸、一分の波の3パターン。
- **オートの照明**：室内がゆっくり暗くなり、水が当たった石の周辺だけがほのかに照らされます。注水の余韻とともに明かりも弱まり、セルフに戻すと通常の明るさに戻ります。
- **静かな時間**：画面の減光、音量・音の距離の調整、3・5・10・20分または自由時間。
- **石の反応**：表面と内部の温度、局所的な冷却、残った水と下段への滴下に応じて音が変化。
- **素材の表情**：割れ目と粒子を持つ石、濡れた石の光沢、木目、銅の柄杓、水面の反射、ゆっくり広がる湯気。素材の描画はキャッシュして再利用します。
- **小さな遊び**：黒い柱型ストーブの小さな銘板と、石の中にひっそり隠れた反応。スコアや大きな効果音はありません。

## 起動

Node.js 20.3以上を使用します。外部npmパッケージのインストールやビルドは不要です。

```sh
npm start
```

ブラウザで http://localhost:8080 を開き、入口のボタンを押してください。PowerShellの実行ポリシーで `npm` が止まる場合は `npm.cmd start` が使えます。

## 操作

休息中は画面下の一時停止・操作ボタンが使えます。「もう一杯、かける」で手動操作へ戻れます。

「水を汲む」または画面のバケツを押し、石を長押しすると注げます。離すと注水が止まります。柄杓をバケツへドラッグして水を汲むこともできます。

「押して注ぐ」ボタンはSpace / Enterの長押しにも対応します。「オートロウリュ」では操作せずに聴けます。右上の月のボタンで減光、調整ボタンで音と時間を設定します。

## 構成

```text
public/
  index.html       画面と操作パネル
  style.css        レイアウトと減光モード
  app.js           描画・水と熱のモデル・音声合成
server.mjs         HTTP配信と /health
tests/
  simulation.cjs   状態遷移・温度・水量・タイマーの検査
```

## 検査

リポジトリのルートで実行します。

```sh
node --check public/app.js
node --check server.mjs
node tests/simulation.cjs
```

シミュレーション検査はDOMと音声ノードを模した環境で実行し、途中の注水・休息への移行・独立した時計・一時停止からの終了・暗い終了画面・温度と水量の不変条件を確認します。実際の音質や端末ごとの挙動は、ブラウザで別途確認してください。

## ホスティング

Node.jsを実行できる環境では `npm start` で配信できます。`PORT`環境変数を読み、未設定なら8080を使用し、`0.0.0.0`で待ち受けます。`GET /health` は `ok` を返します。APIキーやデータベースは不要です。

静的ホスティングの場合は `public/` の内容を配信します。GitHub Pagesでは、`main`へのpush時にGitHub Actionsが検査を実行し、`public/`を自動公開します。手動で公開し直す場合はActionsの「Deploy Yohaku to GitHub Pages」から実行できます。

## 実装上の前提

- 温度・蒸発は体験用に調整した簡易モデルです。
- 再生開始にはブラウザ上での操作が必要です。
- OS・ブラウザによっては、画面ロック中やバックグラウンドで音声が停止します。
- 設定はブラウザ内のlocalStorageに保存します。
- Google Fontsを読み込みます。利用できない場合は端末の標準フォントで表示します。
